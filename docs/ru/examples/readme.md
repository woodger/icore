# Примеры

[English](../../examples/readme.md) | Русский | [简体中文](../../zh/examples/readme.md)

> Русский перевод английской версии. При расхождении актуальной считается английская версия.

Эти примеры показывают, как приложение использует `icore`. Начните с нужной задачи; ниже собраны прямые API для случаев, когда приложению требуется больше контроля.

Часть подробных примеров пока доступна только на английском; их названия ниже переведены для навигации.

## API для существующих интеграций

Эти API остаются публичными, но новые приложения обычно начинают с API из разделов выше.

- [Поиск команды напрямую](../../examples/command-resolution.md) описывает `resolveCommandFromArgs(...)`.
- [Подготовка, выполнение и разбор аргументов напрямую](../../examples/two-phase-primitives.md) описывает `parseOptionsDetailed(...)` и `parseOptionsSubsetDetailed(...)`.
